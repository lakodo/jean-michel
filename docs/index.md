# Jean-Michel

!!! warning "WIP / Prototype"
    Jean-Michel is currently an early prototype.
    It is not production-ready and not dev-ready yet.

An opinionated AI assistant for rigorous, constrained, asynchronous software development.

Jean-Michel orchestrates background engineering work with clear scope boundaries, isolated worktrees, and reviewable commits.
